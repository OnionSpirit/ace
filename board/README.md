# ACE Board

Хранилище `/home/ivanm/code/cxx/ace/board` — активный реестр задач ACE.
Каждая карточка в `Tasks/` хранит её текущий статус, утверждённый план, ход
работы и результаты проверок. `agents/ISSUES.md`, `agents/TESTING.md` и
`agents/BENCHMARKS.md` сохраняют архивное описание и инвентарь.

## Открыть доску

1. Откройте палитру Obsidian: **Ctrl+P → Dispatch: Open board**.
2. Выберите карточку. Папки `issues`, `todo`, `testing` и `benchmarks` —
   источник для одной общей доски; Dispatch сканирует их рекурсивно.
3. В режиме чтения нажмите **Взять задачу**.

Кнопка сразу открывает OpenCode в корне ACE с путём к конкретной карточке.
Она начинает read-only исследование и согласование плана по `AGENTS.md`; не
утверждает ещё не представленный план и не расширяет разрешения OpenCode.

## Карточки и статусы

Карточка имеет уникальный `id` с namespace (`issue:B82`, `testing:B14`,
`todo:T2`, `benchmark:BM1`), исходный `source_id`, тип, статус, исходный
статус и путь к архивному документу. Это исключает коллизии одинаковых ID
между разными реестрами.

Колонки: Очередь (`Открыто`), Исследуется, В работе, На проверке,
Заблокировано и Готово (`Решено`). Перетаскивание меняет только поле `status`
карточки; порядок хранится в `rank`.

Сохранённый или утверждённый план записывайте в существующую карточку задачи,
а не в отдельный документ и не в дубликат карточки. Для новой работы создайте
карточку в подходящей папке и сохраните связь с техническим контекстом.

## Миграция

В `MIGRATION.json` зафиксированы SHA-256 исходных документов, правила mapping
статусов и число импортированных записей:

- 92 issue/technical-note;
- 9 TODO;
- 447 пунктов coverage-плана;
- 26 benchmark-сценариев.

Всего: 574 карточки. B64 со статусом «Частично решено» находится в колонке
«На проверке»; записи о намеренном контракте API и реализованные benchmark
сценарии находятся в «Готово».

Lifecycle hooks Dispatch не настроены. Badge запуска означает только старт
сессии; после её фактического завершения очистите badge через меню. Не
выставляйте `Решено` по факту запуска агента.
