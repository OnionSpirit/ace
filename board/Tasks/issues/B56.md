## Архивная запись

### B56. Public `listener_entity::accept` overload не компилируется при instantiation

- **Статус:** Открыто.
- **Приоритет:** Средний.
- **Файл:** `include/ace/net.h` (`listener_entity::accept(sockaddr*, const
  socklen_t*, int)`, `accept_query` constructor).
- **Симптом:** public overload принимает `const socklen_t*`, но передаёт его
  constructor-у, ожидающему writable `socklen_t*`; kernel accept изменяет длину.
  Template body не диагностируется, пока overload не инстанцирован, поэтому
  текущая сборка проходит.
- **Предлагаемое решение:** публично принимать корректный in/out pointer либо
  изменить API на безопасную owned result structure; не использовать const-cast.
- **Проверка решения:** отдельный consumer compile-test инстанцирует overload;
  runtime loopback проверяет обновлённые address и addrlen, short buffer и error.
  Обновить Doxygen direction `[in,out]`.

## Утверждённое расширение — 2026-10-02

Пользователь: «Да разрешаю» — short/null output включён в B56.

- Сохранить capacity непосредственно перед submit, до того как kernel заменит
  addrlen фактической длиной. Копировать в metadata не больше исходной capacity,
  returned length и размера IPv4 storage; отсутствующие bytes обнулять.
- `addr == nullptr` означает отсутствие address output; addrlen игнорируется.
  При ненулевом addr и нулевом addrlen сохранить kernel error contract.
- Добавить ASan regressions для реально коротких allocations, zero capacity,
  null output, missing length; проверить exact payload, output bounds, metadata,
  завершение/cancellation и descriptor cleanup через public accept API.
- Обновить README, Doxygen, INDEX/TESTING/ISSUES и карточку; новый benchmark не
  нужен для bounded copy до sizeof(sockaddr_in) без allocations/syscalls.
- RED: целевые ASan regressions до исправления. GREEN: те же regressions,
  shuffle repeat 10, затем полные ASan+LSan и TSan suites в build/build-tsan.


## Итог расширения — 2026-10-02

- `accept_query::setup_query()` сохраняет исходную capacity, не читает addrlen
  при null addr. В `await_resume()` локальный zeroed sockaddr_in получает
  не больше min(capacity, returned length, sizeof(sockaddr_in)); локальный
  временный объект также сохраняет корректность aliasing с адресными metadata.
- Null output и zero capacity дают zeroed peer metadata; kernel EFAULT для
  nonnull addr с missing length сохраняется. Дополнительных allocations,
  syscalls и locks нет. Doxygen описывает ownership/lifetime и output contract.
- Пять новых regressions: `listener_accept_short_address_storage`,
  `listener_accept_zero_address_capacity`, `listener_accept_null_address_storage`,
  `listener_accept_missing_address_length`, `listener_accept_optional_address_cancellation`.
